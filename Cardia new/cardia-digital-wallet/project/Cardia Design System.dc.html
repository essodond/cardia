Card Template System
Une carte CARDIA n'est pas une image. C'est un modèle structuré (pays, catégorie, type, recto, verso, champs) combiné aux données de l'utilisateur. Cinq layouts de base couvrent l'ensemble du catalogue ; un nouveau document se déclare en données, sans nouveau code d'interface.
